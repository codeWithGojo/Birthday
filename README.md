Birthday site for Victory (Amarachi).

## Banter video

The “Do not open this, Victory” section is on the `feature/birthday-banter` branch. Place Favour's video at `favour-banter.mp4` in the repository root before merging this branch into `main`. Use an MP4 with H.264 video and AAC audio so it plays on iPhone and desktop browsers. The video begins only after Victory presses the second reveal button and pauses when she leaves the section.
